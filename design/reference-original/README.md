# Референсы первоначального силуэта

**Приоритет №1 для геометрии корпуса** — ранний фотопланшет трёх вариантов **MONOLITH / CLEAR SMOKE / CERAMIC**, выбранный владельцем как лучший по пропорциям (длинный, почти прямой, без талии/S-изгиба).

![Миниатюра выбранного оригинального рендера](preferred-render-thumb.jpg)

- [Сохранённая миниатюра выбранного изображения](preferred-render-thumb.jpg) — **150×137 px**, маленький JPG-превью. Она хранится непосредственно в GitHub и не зависит от срока жизни ссылок ChatGPT.
- **Полное исходное PNG ~1312×1199 px пока не загружено в этот репозиторий**. Для инженерной работы с изображением в исходном разрешении владелец или агент с загрузкой бинарных файлов должен положить PNG в этот каталог, например `preferred-render-full.png`. Нельзя увеличивать миниатюру и считать её точным CAD-чертежом.
- Источник — изображение, созданное в предыдущем ChatGPT-диалоге. Временные подписанные адреса загрузки не хранятся в репозитории; для CAD желательно дополнительно загрузить исходное PNG без потери разрешения.

**ВАЖНО:** миниатюра показывает устаревшую крестовину, три функциональные кнопки у нижней части и отверстия динамика не по центру. **Эти детали НЕ КОПИРОВАТЬ.** Актуальные органы управления и решётка динамика — в [CAD-задании](../../docs/CAD_HANDOFF_PROMPT.md) и [R0.2 семейство SVG](../concepts/brick-family-r02.svg). При конфликте: CAD-задание и свежие утверждённые решения выше старых декоративных изображений.
