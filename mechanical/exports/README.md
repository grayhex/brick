# Approved CAD exports

Здесь будут STEP сборки и отдельных деталей, STL/3MF для прототипов. Вместе с экспортом записать механическую ревизию `M_REV`, CAD source commit, версию генератора, единицы мм, измерения bbox, результаты collision/fit и испытания на физическом образце. Черновые объёмные экспорты могут идти через закрытые CI artifacts, проверенные snapshots — в git/release. Пока нет реальной master CAD сборки — файлов производства нет.

Заготовка манифеста экспорта — [export-manifest.template.yml](export-manifest.template.yml): ревизия, SHA исходника и параметров, версия генератора, габариты, SHA-256 файлов и результат проверки посадки. Без манифеста экспорт в git не кладут.
