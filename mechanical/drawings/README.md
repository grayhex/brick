# Mechanical drawings / validation

Здесь появятся реальные front/rear/left/right/bottom/top views, два сечения (LCD/FPC, батарея/PCB), exploded view, идентификаторы частей, материалы, допуски, чертёж крепежа, fit/collision report и результаты 1:1 печати. Исходник — `../src/`. Старые SVG из `design/` не являются размерными заводскими чертежами. Все размеры/допуски до проверки на физическом образце — **proposed**.

Чертежей пока нет. Есть заготовка протокола проверки: [fit-check.template.csv](fit-check.template.csv) — по строке на каждую проверку из [CAD-задания](../../docs/CAD_HANDOFF_PROMPT.md) и [чек-листа](../../docs/RELEASE_COMPLETENESS_CHECKLIST.md) (Gate 2); поля результата пустые, пока нет физического образца. Автоматический отчёт генератора — [../validation.md](../validation.md): он не заменяет протокол.
