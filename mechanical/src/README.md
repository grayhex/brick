# Parametric CAD — source of truth

Источник истины — [../params.json](../params.json) и Python-код CadQuery (OpenCascade) в этом каталоге. **Единственная master-модель в STL не создаётся.** Команды воспроизведения и зависимости — в [../README.md](../README.md). Для R0.2 следовать [CAD brief](../../docs/CAD_HANDOFF_PROMPT.md); экспорт попадает в `../build/` (не в git) или, после проверки, в `../exports/`; размеры и виды — в `../drawings/`. Существующие `../inbox/` STL — лишь проверяемый вход.

| Файл | Что делает |
| --- | --- |
| `geom.py` | примитивы в системе координат спецификации (X вправо, Y вниз, Z в толщину, начало — левый верхний внешний угол лицевой панели); отображение на Y-вверх CadQuery — поворот на 180° вокруг X, ничего не зеркалится |
| `params.py` | чтение `params.json`, выбор толщины 20 / 22 мм, шов посередине толщины (допущение для макета) |
| `case.py` | передний и задний корпус: окно LCD, отверстия кнопок, решётка динамика только спереди, вырез USB-C только на нижнем торце |
| `keys.py` | восемь кнопок отдельными телами (три функциональных, четыре направления, одна Action) |
| `display.py` | заглушка стопки LCD за окном (кандидат, не реальный компонент) |
| `build.py` | сборка, проверки, экспорт STEP/STL, отчёт |
| `check_params.py` | проверки чисел без CAD-ядра |
| `test_validation.py` | намеренно ломает модель и убеждается, что проверка краснеет |

Допущения генератора (зазор отверстия 0,3 мм, выступание кнопки 1,5 мм, шаг и диаметр отверстий решётки, вырез USB-C 9,5×3,5 мм, толщина стопки LCD 4,7 мм) собраны в `prototype_assumptions` файла `params.json`: это стартовые инженерные допущения для печатного макета, а не решения владельца и не допуски литья.
