# Brick mechanical CAD

**Рабочий источник геометрии должен быть параметрическим.** [src](src/README.md) — CadQuery/FreeCAD исходники; [drawings](drawings/README.md) — реальные чертежи/разрезы/fit; [exports](exports/README.md) — проверенные STEP/STL. `inbox/buildcad-r0.1/` — архив присланных бинарных STL с известными замечаниями ([аудит](../docs/MECHANICAL_MOCKUP_REVIEW.md)); не изменять и не использовать как production master.

CAD brief: [CAD_HANDOFF_PROMPT](../docs/CAD_HANDOFF_PROMPT.md). Согласовано: приблизительный корпус 175×80, 4 раздельные жёлтые круглые кнопки направлений, 1 гладкая Action, MODE/SELECT/START под LCD, единственный speaker outlet спереди по центру внизу, USB-C на нижнем торце; три finishes на одной базе. Пока не определены толщина, батарея, LCD/FPC, PCB outline, допуски и материал оснастки.
