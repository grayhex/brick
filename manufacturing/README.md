# Brick manufacturing — 100–500 units

**Ещё не готово к производству**: пока нет утверждённой PCB, батареи, экрана, корпуса или проверенных заводских тестов.

- [assembly](assembly/README.md) — операционная сборка, DFM, материалы, крепления.
- [test-jig](test-jig/README.md) — оснастка SWD/USB и аппаратные EOL проверки.
- [qa](qa/README.md) — критерии PASS/FAIL, серийные номера и отчёты.

Процесс: EVT (первые платы и измерения) → DVT (долговечность, механика, зарядка, радио, ESD, акустика) → PVT (пилотная линия, yield, повторяемость тестов) → партия. Для каждой фазы фиксировать `H_REV`, `M_REV`, `fw`, данные испытаний и решение go/no-go. [Полный перечень](../docs/RELEASE_COMPLETENESS_CHECKLIST.md).
