# Заводской тестер — план, оборудования ещё нет

До PCB freeze предусмотреть SWD/USB и тест-площадки. Будущая оснастка и диагностическая прошивка должны проверять: ID/серийный номер, напряжения и защиту LiPo/зарядку, sleep current, все **8** кнопок (4+1+3), переключатель питания и громкость, 10×20 LCD + правую зону, белую подсветку, динамик, BLE GATT, USB-C data/DFU и recovery. Результат каждой проверяемой единицы записывается в [QA](../qa/README.md) с hardware/mechanical/firmware versions и реальными измерениями. Порогов PASS/FAIL **пока нет**.

Перечень проверок со ссылками на требования — [test-plan.csv](test-plan.csv): 19 пунктов (`EOL-01`…`EOL-19`). Для каждого указано, где он нужен (EVT, DVT, PVT, конец линии), чем измеряется и записан ли предел: пределы с пометкой `open` остаются `TBD`, пока нет образцов. Ни оснастки, ни диагностической прошивки пока нет; план — основа для их задания.
