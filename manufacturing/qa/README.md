# QA / EVT / DVT / PVT

Ещё нет физических серийных устройств и протоколов. [unit-test-record.template.csv](unit-test-record.template.csv) определяет **поля логирования**, а не реальные результаты испытаний.

Фиксировать `unit_id`, H/M/fw, fixture_rev, тестировщика, дату, измерения, дефект/rework, фото и решение PASS/FAIL. Нужны gold sample для трёх корпусов, испытания на чёткость LCD/подсветку, раздельные нажатия, звук, батарею и зарядку, ESD/RF/USB-C, качество прозрачного и непрозрачных корпусов, ресурс кнопок. Критерии зафиксировать только после физических образцов и согласования. Не публиковать серийные личные данные.
