# BLE companion — будущий мобильный клиент

**Пока нет приложения.** Подтверждено: Bluetooth **только BLE для связи с телефоном, настроек и синхронизации**; аудио исключительно во встроенный динамик, без BT наушников/A2DP/LE Audio.

До первой Android/iOS реализации согласовать GATT schema/version, pairing/bonding и разрешения записи, модель настроек/статистики, совместимость прошивок, требования к расходу энергии. USB-C DFU/recovery обязателен; BLE OTA опционален после тестов на прерывание обновления. Не создавать фиктивные мобильные экраны или бинарные «выпуски».

Что уже есть: [gatt-draft.md](gatt-draft.md) — **черновик** схемы GATT (PROPOSED) на основе данных профиля прошивки: настройки, рекорды, сведения об устройстве, заряд. Это не реализация и не утверждённый протокол.
