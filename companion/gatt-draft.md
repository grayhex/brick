# Черновик схемы BLE GATT для телефона

**Статус: PROPOSED, не реализовано и не утверждено владельцем.** Подтверждено только: BLE нужен для связи с телефоном, настроек и синхронизации; весь звук идёт во встроенный динамик ([PRD](../docs/PRODUCT_REQUIREMENTS.md) BT-01, BT-02). Схема ниже вытекает из данных, которые у прошивки уже есть (`firmware/include/brick/save.h`, профиль версии 1), и закрывает пункт «черновик схемы GATT» из [ROADMAP](../docs/ROADMAP.md). Прежде чем её реализовывать, нужен ADR и проверка на образце (гейт G2).

## Что синхронизируется (данные уже существуют)

| Данные | Откуда | Размер и форма |
| --- | --- | --- |
| Настройки | `bk_settings_t` | звук вкл/выкл (0/1), уровень подсветки (0…`BK_LIGHT_MAX` = 2). Положение меню (`last_game`, `last_speed`, `last_level`, `last_mode`) телефону не нужно |
| Рекорды | `bk_record_t` | `game_uid` u16, `mode` u16, `score` u32; не более `BK_MAX_RECORDS` = 96 записей. При одном варианте на игру (ADR-036) `mode` всегда 0 |
| Сведения об устройстве | сборка и плата | модель, версии прошивки, платы и механики, серийный номер |
| Заряд | измерение батареи | процент |

Состояние партии в середине игры **не сохраняется** и не синхронизируется ([FIRMWARE_ARCHITECTURE §8](../docs/FIRMWARE_ARCHITECTURE.md)).

## Сервисы и характеристики

UUID собственных сервисов в этом файле **не выдуманы**: перед реализацией сгенерировать случайную 128-битную базу, записать её здесь и в ADR. Стандартные сервисы берутся по присвоенным номерам Bluetooth SIG.

| Сервис | Характеристика | Доступ | Содержимое | Защита |
| --- | --- | --- | --- | --- |
| Device Information (0x180A, стандартный) | Manufacturer Name, Model Number, Serial Number, Hardware Revision, Firmware Revision | чтение | строки; в `Hardware Revision` — `H_REV`, в `Firmware Revision` — версия прошивки; `M_REV` — в характеристике Brick Info ниже | без защиты |
| Battery (0x180F, стандартный) | Battery Level | чтение, уведомление | 0…100 % | без защиты |
| Brick Info (свой) | Schema Version | чтение | u8, версия схемы (начать с 1); телефон отказывается писать, если версия неизвестна | без защиты |
| Brick Info (свой) | Revisions | чтение | `H_REV`, `M_REV`, `fw` и минимальная совместимая ревизия железа | без защиты |
| Brick Settings (свой) | Settings | чтение, запись | u8 версия формата, u8 звук, u8 подсветка | запись только на зашифрованном и аутентифицированном соединении |
| Brick Records (свой) | Records Count | чтение | u16, число записей | чтение — на зашифрованном соединении |
| Brick Records (свой) | Records Page | чтение с индексом | страница записей по `game_uid`, `mode`, `score`; размер страницы по MTU | то же |
| Brick Control (свой) | Command | запись | u8 команда: сбросить рекорды | запись только на аутентифицированном соединении, действие подтверждается на самом устройстве |

## Решения, которые нужны от владельца и из проверок

| Вопрос | Предложение | Состояние |
| --- | --- | --- |
| Сопряжение | LE Secure Connections с сохранением связи; у устройства есть экран и кнопки, значит возможно сравнение числа на экране (**не** «просто подключить») | OPEN |
| Запись без пары | запрещена; чтение сведений об устройстве и заряда разрешено | OPEN |
| Сброс рекордов с телефона | только с подтверждением на устройстве | OPEN |
| Вход в DFU по BLE | **не предусматривать в первой версии**: основной путь — USB-C, BLE OTA необязателен и только после испытаний на прерывание обновления (PRD §6) | OPEN |
| Что делает телефон при неизвестной версии схемы | показывает «обновите приложение» и ничего не пишет | предложение |
| Расход энергии | интервал рекламы и соединения измерить на плате, влияние на 20–30 ч оценить измерением | не измерено |
| Приложение | не создавать, пока не выбран MCU и не проверен профиль на образце; фиктивных экранов и «выпусков» не делать | OPEN |

## Проверка

Для заводской и приёмочной проверки схема описана в [плане испытаний](../manufacturing/test-jig/test-plan.csv) (`EOL-14`): устройство рекламируется, пара устанавливается, настройки и рекорды читаются и пишутся, неавторизованная запись отклоняется. Тестов на настоящем BLE нет: железа нет.
