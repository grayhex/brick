# PCB — native KiCad source

Здесь будут `*.kicad_pro`, `*.kicad_sch`, `*.kicad_pcb`, локальные проверенные библиотеки/footprints и проект 3D платы. **Сейчас PCB нет.**

Когда будут утверждены LCD/FPC, питание, BLE, разъёмы, PCB outline и кнопочная механика, выполнить ERC/DRC, DFM/DFT, проверить реальные pinout и зазоры по `mechanical/`. Актуальные BOM/MPN в [components](../components/README.md). Герберы, координаты сборки и сверловку генерировать в [fabrication](../fabrication/README.md), не редактировать вручную.
