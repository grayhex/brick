# KiCad: соглашения для проекта Brick

**Статус: договорённость до появления проекта.** KiCad-файлов пока нет; эти правила нужны, чтобы первая плата сразу легла в структуру из [REPOSITORY_STRUCTURE.md](../../docs/REPOSITORY_STRUCTURE.md).

## Имена и состав

* Проект `brick-main`: `brick-main.kicad_pro`, `.kicad_sch`, `.kicad_pcb` в этом каталоге. Если дисплей будет отдельной платой (как у Pi Tin), второй проект получает своё имя и свою ревизию.
* Библиотеки символов и посадочных мест — локальные, в `hardware/pcb/lib/` (`brick.kicad_sym`, `brick.pretty/`, `brick.3dshapes/`), каждая деталь с MPN и ссылкой на даташит в полях. Сторонние библиотеки копировать только после проверки лицензии ([REFERENCE_PROJECTS](../../docs/REFERENCE_PROJECTS.md), [THIRD_PARTY](../../THIRD_PARTY.md)).
* Поля каждой детали: `MPN`, `Manufacturer`, `Datasheet`, `Status` (`CANDIDATE` / `SAMPLED` / `QUALIFIED` / `REJECTED`, как в [components](../components/README.md)). BOM выгружается из схемы, а не ведётся вручную.
* Ревизия платы — в основной надписи схемы и на шёлке: `H0.1`, `H0.2`… ([revisions.md](revisions.md)). Новая ревизия — новый тег в git и новый каталог в `hardware/fabrication/`.

## Что обязательно пройти до заводских файлов

1. Схема: ERC без ошибок либо с записанными и объяснёнными исключениями.
2. Плата: DRC без ошибок, правила платы (зазоры, отверстия, слои) — по данным выбранного завода, а не «по умолчанию».
3. Сверка с механикой: контур, отверстия, посадка разъёмов и кнопок по `mechanical/` той же ревизии `M_REV`.
4. Проверка реальных распиновок: дисплей, USB-C, батарея, динамик — по даташитам точных ревизий.
5. Обзор DFM/DFT сборщиком; площадки SWD, USB и испытательные точки ([требования HW-13](requirements.md)).

## Выпуск заводских файлов

Герберы, сверловка, координаты, BOM и чертежи **генерируются** из KiCad командой `kicad-cli` (команды и версии фиксируются в манифесте пакета, см. [package.template.yml](../fabrication/package.template.yml)) и кладутся в `hardware/fabrication/<H_REV>/`. Вручную править выгрузку нельзя; ошибка исправляется в KiCad и выгрузка делается заново. Скрипт выгрузки появится вместе с первым проектом: сейчас запускать нечего.
