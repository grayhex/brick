# Tetris: что портировано из ApolloBrickGames

**Источник:** [grayhex/ApolloBrickGames](https://github.com/grayhex/ApolloBrickGames), коммит `abd7c3426f28222b54db2fe280597d7578e7191c` (`main`, 2026-10-18), файлы `src/brick/base.ts`, `src/brick/games/tetris.ts`, `src/brick/games/tetris/{core,shapes,variants}.ts`, `src/core/rng.ts`.
**Реализация:** `firmware/games/tetris/`, C11. **Статус:** прототип; **не верифицированная ROM-реализация**, а перенос правил эталона (который сам опирается на открытый симулятор-донор и ROM-измерения для части чисел).

## 1. Объём порта (CONFIRMED владельцем: «пока базовый вариант, все 51 не нужны»)

| Портировано | Не портировано (отложено) |
| --- | --- |
| Вариант **01** — донорский класс `I`, тип 1 («Обычный»): семь тетрамино, поворот по часовой, снятие рядов, очки 1/3/7/15, скорость по таблице B0202, рост скорости каждые 1000 очков, стартовый уровень = случайные ряды | Варианты 02–51 эталона: спецфигуры (суперточка, суперпушка, грязевая пушка, супербомба), особые семейства (рассыпающиеся, кислотные, сквозные, случайные), классы `J`/`K`/`L`/`M` (новые ряды по таймеру, смена фигуры вместо поворота, сдвиг поля), перевёрнутое поле |
| ГСЧ mulberry32, битово совпадающий с эталоном | Pentix (`pentixDef`, отдельная игра; каталог пентамино в порт не вошёл) |
| Анимация стирания ряда и заливка поля при конце игры | Сценки взрыва и стекания (нужны только спецфигурам), надбавки к времени падения (+50 мс) |
| Превью NEXT 4×4, события для звука | Мелодии и заставки донора |

Архитектура допускает добавление вариантов: у игры есть `mode_count`, меню умеет выбирать режим (проверено на заглушках в `tests/support/stub_game.c`), а сценки реализованы общим механизмом основы. Для Tetris `mode_count = 1`.

## 2. Правила базового варианта

Таблица повторяет документацию эталона (`docs/brick/tetris.md`); колонка «основание» — как там заявлено, **мы это не перепроверяли** независимо (кроме самосогласованности порта с кодом эталона, см. [CONFORMANCE.md](CONFORMANCE.md)).

| Правило | Значение | Основание (по эталону) |
| --- | --- | --- |
| Поле | 10 × 20; внутри `board[y*10+x]`, `y = 0` — низ | донор |
| Появление | колонка 4, нижний ряд фигуры в верхней строке, остальное над экраном; не поместилась — конец игры | донор `newPiece` |
| Фигуры | Z, S, палка, T, квадрат, L, зеркальная L; равновероятны, со случайным начальным углом | донор |
| Гравитация | время падения на клетку `counts × 2048 / 690000` с, `counts = 150, 120, 100, 82, 60, 41, 35, 31, 27, 25` для скоростей 1…10 → 445…74 мс; на 60 Гц период дробный, остаток переносится | таблица ROM Apollo B0202 `0x0C38` (измерено эталоном по BrickEmuPy) |
| После посадки | новая фигура появляется на следующем шаге гравитации | донор |
| Сдвиг | немедленный первый шаг, после ~130 мс (8 тактов) повтор каждый такт | трасса B0202; первый сдвиг без задержки — **намеренное отличие эталона от оригинала** |
| «Вниз» | мягкое падение раз в такт, сбрасывает таймер гравитации | трасса B0202 |
| Поворот | на 90° по часовой по **фронту** нажатия (удержание не повторяет); у стенки фигуру возвращают в поле, если места нет — поворота нет; квадрат не вращается | донор, B0202 |
| Очки | 1, 2, 4, 8 за первый…четвёртый ряд одной посадки (1/3/7/15), за пятый и далее по 1; верхняя строка поля не проверяется | B0202 |
| Скорость | +1 за каждые 1000 очков до 10 (на экране 0…9); при максимуме остаётся | B0202 |
| Стартовый уровень N | в начале партии снизу N − 1 случайных рядов (в ряду и клетки, и дыра) | донор |
| Конец игры | новая фигура не поместилась, или после снятия рядов посаженная фигура торчит выше поля | донор |
| Заливка при конце игры | 127 мс на ряд снизу вверх, затем 30 тактов паузы | трассы ROM HT943 (другое семейство прошивок, чем B0202; стирание после заливки не моделируется) |
| Стирание ряда | от колонки фигуры в обе стороны, шаг 60 мс (4 такта) | допущение эталона (не измерено) |

Эталон прямо помечает как **допущения**: шаг анимации стирания, соответствие номеров вариантов номерам настоящего устройства, шанс спецфигур и прочее, относящееся к непортированным вариантам. Они переходят в этот порт без изменений.

## 3. Управление в консоли

| Кнопка | Действие в игре |
| --- | --- |
| ВЛЕВО / ВПРАВО | сдвиг (повтор после ~130 мс) |
| ВНИЗ | мягкое падение |
| ВВЕРХ | поворот (псевдоним большой кнопки, как в эталоне) |
| ACTION (большая) | поворот |
| FN1 / FN3 | пауза / выход (оболочка, не игра) — [UI_MENU.md](UI_MENU.md) |

**Жёсткого сброса на корпусе нет.** Движок его поддерживает (`BK_KEY_FIRE`: вниз до упора, посадка в том же такте; эталон использует его в тестах, а оболочки Apollo с 17 октября 2026 его отключили), консоль клавишу `FIRE` не выдаёт: у корпуса одна кнопка действия. Возможная раскладка (длинное нажатие и т.п.) — отдельное решение (PRD §5).

## 4. Отличия порта от эталона и от настоящего устройства

Структурные (поведение не меняют, проверено побитово):

* замыкания сценки стирания — конечный автомат (`scene kind + elapsed`), кадр анимации вычисляется по прошедшим тактам, а не заранее;
* все массивы фиксированного размера внутри структуры игры, нет кучи;
* `rng.int()` реализован целочисленно (`(r × max) >> 32`) — равен `floor(r/2³² × max)` эталона;
* заливка при конце игры — целочисленная арифметика с теми же константами (`183` такта).

Сознательно сохранено как у эталона, хотя это не «железная» правда: число `double` в таймере гравитации (ADR-018), бесплатный первый сдвиг, повторы ввода по такту 60 Гц.

**Не подтверждено на настоящем устройстве:** ни одно число этого раздела не измерено нами на оригинальных Brick Game; всё, что сильнее «так считает эталон», утверждать нельзя.

* Правила эталона восстановлены автором ApolloBrickGames по открытому симулятору **n0Live/BrickGame** (Java, **MIT**, © 2017 Egor Krasnopolin); уведомление сохранено в [THIRD_PARTY.md](../THIRD_PARTY.md) — этот порт является производным от тех правил и обязан его нести.
* Спрайты меню (крупные цифры и буквы 4×7, мелкие цифры 3×5, иллюстрация Tetris 10×5) скопированы из `src/brick/menuArt.ts` эталона. Эталон помечает цифру «2» и часть иллюстраций как нарисованные по фотографии экрана оригинала, остальное — «в том же стиле». **Статус прав на эти рисунки не установлен**; до публичного или коммерческого выпуска их нужно либо проверить, либо перерисовать (риск R-3 в [DECISIONS.md](DECISIONS.md)).
* У репозитория ApolloBrickGames на момент аудита **нет файла LICENSE**; владелец один, но условия повторного использования для третьих лиц не заданы.
* Звуковые сигналы этого порта — оригинальные заглушки, не транскрипции.
